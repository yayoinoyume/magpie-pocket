# 轻透玻璃移动端设计规范

此规范记录 Magpie Pocket 已确认的视觉方向及当前交互要求，供实现、扩展页面和审查使用。它是一套自定义 Android 设计规范。用户参考图里的玻璃气质通过 Android 原生排版、透明色、边缘高光与柔和阴影实现。

## 1. 视觉基线与优先级

1. 当前用户明确要求和实际数据语义。
2. 本规范中的交互与控件规则。
3. 项目中的共享 tokens 和组件；数值快照见 tokens.json。
4. assets/routing-reference.png 的空间关系、材质气质和信息密度。

参考图中可见的旧分组下拉不属于当前交互要求。自动跟随时保留同样的横向轻透区域，显示当前实际组和策略，并标注“自动跟随”，不提供手动选组箭头。

## 4. 页面结构

### 共用框架

品牌区：浅色主题使用深灰圆角底与浅色鸟，深色主题沿用现有反色鸟标；magpie pocket 字标、当前网关及连接状态，品牌区只做标识，不响应点击；右侧一个 48dp 圆形主题入口。底部为“概览、路由、用量、请求、更多”，外层胶囊左右 16dp 边距、宽度不变，五项等分。选中项用淡紫胶囊与主色图标文字，其他项为次要文字；图标 21dp、文字 11sp、图标与文字间距 4dp，320dp 宽下不换行、不截断。导航有文字，不能只剩五个难以分辨的图标。

### 概览 · 现在

页头（标题、副标题“现在”、右侧一个 48dp 圆形主题动作）→ 状态条 → 今日 2×2 → 当前活动 → 需要留意 → 今日 24 小时 → 页脚口径。

- 状态条一行：连接状态、演示标记与“统计日 YYYY-MM-DD”；连接本身可点，切到“更多”的网关分组。
- 今日 2×2：今日请求（附“截至 HH:mm”）、成功率（附“N 次最终失败”）、首响均值（附“N 个流式样本”）、今日费用（附“N 次未计价”）。任一缺值输出“—”，不写 0，也不借别的周期补。
- 当前活动：最多 3 条处理中请求，同一秒基准刷新耗时；空态写“当前没有处理中的请求”。点击进入该请求的当前实时路由，不把最新请求错误地固定为历史。
- 需要留意：只在存在额度告警时出现，一行告警加“查看”，跳到用量页的额度子页；多条告警只在同一行补“另有 N 个额度窗口接近上限”。没有告警时整段不占位。
- 今日 24 小时：上游小时桶柱图，零桶保留空位，只标首、中、末三个时间；没有数据写“暂无趋势数据”。
- 页脚：一句固定口径“成功含改道；费用只统计已计价调用。”，数据不完整或过期时追加对应说明。
- 本页明确不做 14 天切换、不做解码速度、不做独立额度卡、不显示昨日同期。周期对比属于用量，额度明细属于用量，解码速度只在用量出现。

### 路由 · 这一次

页头（标题、副标题“这一次”、右侧状态胶囊）→ 焦点请求卡 → 选路画布 → 为什么选它 → 尝试过程 → 上下文构成 → 页脚累计一行。

- 状态胶囊只有六种：实时、演示、离线、同步中、未连接、不可观测。
- 焦点请求卡用 KvGrid 给四行：来源、路由组、状态、改道次数；卡片顶部是应答模型（缺失时用请求模型）与状态标签。末行是跟随状态：左侧“自动跟随”或“历史固定”，固定时右侧给“返回实时”，整行至少 48dp。
- 选路画布仍按请求来源 → magpie 中心节点 → 供应商/账号绘制；组内供应商多于两个时右上角给“更多供应商”，不挤压连线本身。
- 为什么选它：分节标题带“N 条证据”，正文只放一行摘要，完整证据在抽屉里。
- 尝试过程：与请求详情共用同一条时间线，条目状态来自同一个映射；服务端未返回时写“服务端未返回尝试时间线”，不补造条目。
- 上下文构成：按 token 从大到小；三段以内原样成段，超过三段时最大的两段独立成段，其余合并成「其他」（若前两段已有「其他」，合并段写作「其余」）；图例每段只给 token 数（与 magpie 一致，不写占 prompt 的百分比）；条按窗口画：窗口已知时每段宽度 = 该段 token ÷ 窗口，未用部分是底色（0.4% 就只画一丝，绝不铺满）；窗口未知（null 或 0）时才退回「各段相对比例」并铺满；条右侧写「窗口上限 · 已用占比」，占比分母是窗口，不足窗口时不进位到 100%；0 token 的段不画也不进图例；无构成数据时只显示「暂无上下文明细」，不画空条；共最多三段；七种 kind 中文名为系统提示 / 工具 / 技能 / 记忆 / 文件 / 工具结果 / 会话；标题右侧给本次总 token。
- 页脚累计只在 trace 可观测且带 totals 时输出一行“本次启动以来 X 请求 · Y 次改道 · Z 次最终失败”；没有 totals 时整行不出现，单项缺失印“—”，不印 0 冒充实测。
- 自动焦点：优先实际处理中请求，按真实开始时间取最新；没有处理中请求时显示最近已观察请求。并发计数统计全部组，不伪装成只有当前焦点一个请求。
- 焦点变化同步组、模型、供应商、实际账号、尝试、状态、解释和上下文，不能只换标题。
- 组信息缺失时显示请求中的真实组标识；无组请求显示“直接路由”。没有请求则显示“等待路由请求”，不挑第一个配置组补图。
- 连线轻、拐角圆，活动路径为紫色，真实选中的账号以淡紫底和细边缘强调；非活动节点保持次级表面。
- 只根据真实 trace 绘制流动光点和账号呼吸。请求完成后短暂结算反馈只消费一次，然后静止；断网、后台、系统或应用减少动态效果都停止动画。
- 没有明确的新需求时，不另外增加暂停自动跟随的偏好开关。固定历史后，新的实时请求不能替换其组、账号或上下文；“返回实时”恢复全局自动跟随。详情弹窗独立保持原请求，不随后台 trace 跳动。
- 连接、网关重启 epoch、请求 ID 一起确定详情身份，不能跨连接借用旧数据。

### 请求 · 账本

页头（标题、副标题“账本”、右侧“实时/历史”胶囊与日历）→ 搜索 → 筛选 → 计数行 → 请求行。

- 搜索匹配模型、来源与路由组，输入去抖后生效，有内容时给 48dp 清除按钮。
- 筛选只画当前连接支持的项，按“全部、处理中、改道、错误”的枚举顺序排列；服务端不支持的筛选项不出现，也不留禁用占位。
- 计数行左侧是“最近请求”或“历史请求 · 日期”，右侧“共 N 条”。
- 每条强调模型、状态标签与本地时间；第二行是来源、供应商与打码后的账号；第三行是首响、耗时、输出速度（tok/s，缺失不显示）与 token。
- 行内改道徽标只有在请求带尝试时才印数字；账本行只拿到上游 retried 标记时显示“有改道”，不把 1 当次数。
- 详情抽屉：#路由 ID、状态标签与独立的“改道 N 次”、KvGrid 十一项（开始时间、来源、路由组、请求模型、应答模型、供应商、账号、首响、总耗时、输出速度、Token）、尝试时间线，最后是错误块（终态失败写“最终失败”，否则写“错误信息”）。
- 日期筛选传给 Material 日期选择器的是 UTC 编码的日历日，转换语义不能与真实时间点混淆。

### 用量 · 一段时间

页头（标题“用量”，副标题随子页变）→“用量 / 额度”两格子页胶囊（固定在滚动区外）。

- 用量子页（自上而下）：四档分段（固定，不随列表滚动）→ 费用卡 → Token 卡 → 趋势 → 六维明细。
- 额度子页（自上而下）：总览卡（平均剩余圆环 + 窗口数 + 低于 30% 的项数，下半行给最低与最高）→“全部供应商”标题与已用/剩余胶囊 → 供应商卡片 → 随显示模式变化的底部说明；本子页没有时间分段。
- 四档分段固定为“今日、近 7 天、近 30 天、全部”，没有 14 天档，也没有额外下拉；选中项用 2dp 主色下划线标记，位于列表之外，滚动时不动。
- 两个子页各有一条列表，各自保留滚动位置；锚点“额度”直接打开额度子页。
- 副标题随子页变：用量给所选周期与请求数（“近 7 天 · 1284 次请求”），没有日桶时只写周期名；额度给“实时快照 · N 个供应商”，N 只数答出窗口的供应商，一个都没有时只写“实时快照”。
- 费用卡：周期费用主数值，右上“未计价 N 次”，下一行“信用余额”与“不随周期变化”旁注，底部“仅统计已计价调用”。未计价是次数，不并入金额。
- Token 卡：总 token（含缓存读取）、四段构成条（缓存、未缓存、输出、写入）、一行“缓存命中率 X · 解码速度 Y”。缺值一律“—”。
- 趋势：按日双线，日请求与日费用共用一个横轴；没有数据写“暂无趋势数据”。
- 六维明细：模型、智能体、会话、账号、调用方密钥、供应商密钥按 3×2 芯片排布；排序芯片只提供有数据的指标；表格默认前 5 行，多出的折成“查看全部 N 项”，展开后可“收起”。
- 额度细节：总览圆环取所有窗口“100 − 已用”的算术平均，排除无限额、纯文本与无读数窗口，底部给出最低与最高。供应商卡片按最紧窗口排序，卡头给该窗口的读数。多账号卡默认只显示“N 个账号合计”（只合并两个以上账号共有的窗口：计数相加，百分比只在同套餐内平均）；点整块展开账号行，再点账号右侧箭头才展开该账号的全部窗口，账号行本身不可点。单账号卡直接给最紧窗口与“查看 N 个窗口”。四种形态：有数量（“0 / 500 credits · 0% 剩余”）、只有百分比、余额、无限额、纯文本，无读数不带进度条。窗口行给重置时间，起止时间齐全时再给“比均速快 / 慢 N%”。底部一行说明当前数字是已用还是剩余比例。
- 用量页只放统计，网关、供应商目录、隐私掩码与显示偏好都属于“更多”。

### 更多

标题“更多”与说明“数据、网关、偏好与关于” → 网关（连接名与地址、五项服务能力、配置网关连接、断开并回演示模式）→ 数据（供应商目录、隐私掩码）→ 偏好（显示偏好、后台保持连接）→ 关于（版本、开源许可）。网关组放最前，连接失败时不用滑过其他组。

- 每组一块 24dp 圆角、18dp 内边距的实色 DataPanel，组标题沿用 12sp 分节标签，组内行之间用分隔线。
- 行高 62dp：30dp 淡紫圆角图标块（主色 16dp 图标）→ 15sp 标题 + 11sp 副标题 → 右侧 20dp chevron；整行可点，最小点击区 48dp，读屏为按钮并读出标题与副标题。
- 供应商行副标题给“N 个供应商 · M 个在线”，隐私行给“近 7 天 N 个值被掩码”；没有数据时退回“查看模型、价格与并发”“查看已屏蔽的敏感内容”，不用 0 冒充实测。
- 后台保持连接行用开关显示当前开/关并直接写偏好，状态与偏好抽屉共用同一份，不另建第二份；显示偏好行打开同一个偏好抽屉。
- 网关组的五项能力只有“可用 / 不可用 / —”三种答案，能力未探到时一律“—”，不借用模型默认值当“可用”；连接失败时组顶部插入一条错误提示，需要凭据给“修改连接”，其他给“重试”。
- 版本行显示安装包的 version name 与“只读观测”，与开源许可行一样是只读信息，不是可点入口。

## 5. 术语

同一批数据在五个页面出现时用同一套叫法，界面文字与本文档保持一致。

- **供应商**：Magpie 上游真正提供模型的服务方。组内成员、账号与模型都挂在供应商下。
- **Web Key**：Magpie 管理端的登录凭证，用于建立会话。它不能与 Cloudflare Access 的 Service Token 互相替代，两层认证要分别填写。
- **API 密钥**：供应商侧的上游密钥，由 Magpie 持有并代调用。界面只显示数量（“N 个密钥”），既不逐个列名也不显示明文。
- **调用方密钥**：调用 Magpie 的客户端密钥，用量页把它当作独立归因维度，与供应商密钥分开统计。
- **额度窗口**：供应商给出的一个限额区间，带窗口标识、单位、已用量与上限（或百分比）、起止与重置时间，以及“无限额”“额度未知”“纯文本”三种特殊状态。一个账号可以有多个窗口。
- **改道**：请求从一个候选（供应商/账号）交接到另一个候选。次数按尝试数减一算，只有一次尝试就是 0；改道与终态无关，改道后仍可能成功或最终失败。
- **重试**：上游 retried 标记，表示同一请求再次发起过尝试。账本行没有尝试明细时只能显示“有改道”，不能把该标记当成次数。
- **最终失败**：终态为失败的请求计数。中间某次尝试失败、随后改道成功的请求不计入。
- **首响**：首个流式片段到达的时间（TTFT）。概览给的是按样本加权的均值，不是中位数。
- **处理中**：请求已开始、尚未定论的状态，与筛选里的“处理中”同义。
- **服务中**：被当前尝试指向、正在为该请求服务的供应商或账号，也就是画布上被强调的那个节点。账号自身状态为忙碌时，行内印的是“处理中”，不另造新词。

## 6. 时间语义

每个区块必须能标出自己属于哪一种时间尺度，且一块只用一种。禁止在一个标签下混两种尺度，也禁止把缺失数据补成 0。

| 尺度 | 覆盖范围 | 出现在 |
|---|---|---|
| 今日 | 服务器统计日（按网关时区换算的 range end），含小时桶 | 概览全部区块 |
| 该周期 | 用量页所选四档之一 | 费用卡、Token 卡、趋势、六维明细 |
| 本次启动以来 | 网关进程自启动的累计（trace totals） | 路由页页脚一行 |
| 实时快照 | 取当前时刻，不随分段变化 | 额度子页（圆环与供应商行同一窗口）、需要留意告警 |

- 概览的日期取自服务器统计日，不是手机本地日期；手机时区只影响时间的显示格式。
- 信用余额是账户级数值，标“不随周期变化”，不参与分段。
- 请求账本的时间是请求开始时间，按手机时区渲染；日期筛选用的是 UTC 日历日，两件事不能混。

## 7. 开关、按钮与浮层

### 开关状态表

| 状态 | 圆点 | 轨道 | 边框 / 辅助 |
|---|---|---|---|
| 浅色开启 | #FFFFFF | #5E59D9 | 可无额外边框 |
| 深色开启 | #101217 | #B0AAFF | 可无额外边框 |
| 浅色关闭 | #6D7283 | #F0F1F6 | 可见轮廓 |
| 深色关闭 | #A5ACBC | #222733 | 可见轮廓 |
| 不可用 | 明确设置降级颜色 | 与圆点仍可区分 | 保留禁用语义，不只隐藏圆点 |

圆点对轨道对比至少 3:1，文字可读性单独检查。选择状态必须能看出位置和形状变化。Compose 应共享 SwitchDefaults.colors 的完整状态定义，避免仅设置 checkedThumbColor 导致主题默认轨道同色。整行至少 48dp，文字与开关对齐，TalkBack 可读出名称和开关状态。

按钮的主次通过底色、文字与间距表达，不靠多重渐变、厚描边或强烈发光。按压最多缩到 0.98，减少动态效果时取消缩放；避免夸张弹簧。浮层在实色或高可读表面上展示数据，底部留键盘与系统 inset，长内容可滚动。

## 8. 连接状态与后台体验

视觉层区分：初次连接、已连接、自动重连、离线、认证失败、接口不兼容。旧数据保留并标注更新状态，不能在重连时闪成空白或伪造全零。认证失败需要真实用户操作，不将无限重试表现成“正在连接”。

仅当需求包含后台保持连接时，使用 Android 合规的用户可见通知与后台控制；不是每个采用本风格的应用都要添加后台服务。没有后台需求仍可在前台联网展示真实数据，不能自动降级成离线或演示模式。通知不暴露服务器地址、邮箱、账号或凭据。后台网络保活和界面动画是两件事：网络可继续观察，屏幕外动画必须停。

不要承诺系统强制停止、深度休眠或厂商电池管理下永不断线。保留重试、网络恢复和重新打开后的恢复路径；不通过永久唤醒锁制造“保活”。

## 9. 还原与验收

- 先检查标题、密度、卡片比例、留白与底栏，之后才微调阴影和高光。
- 同一界面至少查看浅/深两种主题；开关逐一开启再关闭，确认圆点、轨道、语义和状态持久化。
- 常规手机宽、320dp 窄屏和放大字体查看最后一行、长组名、模型名、UTC 偏移是否被遮挡。
- 自动路由用两个不同组的真实或受控请求顺序验证；再验证历史固定、弹窗稳定和返回实时。
- 动效用同一区域两帧验证：处理中变化；历史固定、减少动态、后台和离线静止。
- 演示截图带“演示”标记。测试网关只用虚构地址与凭据，不把生产数据写进截图。
- 可交付源码、APK、参考图或 skill 包中不得包含私钥、签名密码、本机用户名路径、真实服务凭据。发布与外部消息仍按用户授权范围执行。
